# SDT 公众号内置风格

所有正式 HTML 使用逐元素行内样式，不依赖 style 标签、class、id、脚本、外部字体或图片。

| style id | 风格 | 适合内容 |
|---|---|---|
| minimal | 极简黑白 | 方法、诊断、默认发布 |
| essay | 长文随笔 | 人物、观点、个人叙事 |
| business | 商业分析 | 数据、案例、研究 |
| warm | 暖色生活 | 茶、空间、生活方式 |
| editorial | 编辑专栏 | 评论、文化、深度观点 |
| tech | 清爽科技 | AI、工具、产品说明 |

## 选择

- 没有明确偏好时选 minimal。
- Daisy 茶室等空间与生活方式内容优先 warm 或 essay。
- 数据和对标报告优先 business。
- AI 与工具内容优先 tech。
- 严肃评论优先 editorial。

## 兼容性

- 正文字号约 16px，行高 1.75–1.95。
- 每个 p、h1、h2、h3、blockquote、ul、ol、li、pre、code、hr 都写独立 style。
- 图片转换为文字占位，发布前在微信后台替换。
- Markdown 链接保留链接文字，不嵌外部 href。
- 表格转换为文字占位，复杂表格发布前人工重排。
