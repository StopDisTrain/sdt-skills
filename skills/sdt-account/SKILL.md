# SDT 账号建模

把目标账号变成后续所有选题和写作都能引用的事实约束。不要把对主页的印象写成人格事实。

## 输入优先级

1. 用户明确说明的事实和限制
2. 目标账号公开主页与历史内容
3. 产品、空间、服务和客户材料
4. 有证据支持的稳定表达模式
5. 推测，必须单独标注并等待验证

## 工作流

1. 收集主页名称、平台、账号链接、简介、粉丝量和公开联系方式。
2. 读取最近 10–20 条内容，记录主题、形式、语气、场景和可见表现中位数。
3. 提取可信资产：真实职业、经历、空间、产品、方法、可展示过程。
4. 提取商业桥梁：内容最终可以自然连接到什么产品或服务。
5. 定义核心受众、次级受众、常见处境、渴望和抗拒。
6. 定义表达边界：不能声称的身份、不能编造的经历、敏感话题和事实核验要求。
7. 输出“事实 / 推断 / 待确认”三层档案。

## 输出

使用 assets/account-profile.md。必须包含：

- 一句话定位
- 人设与可信资产
- 产品和购买场景
- 目标受众与核心张力
- 稳定语气、内容形式和视觉线索
- 已验证强项与历史中位表现
- 允许的产品落点
- 禁止编造清单
- 待确认项

## 质量门

- 每项关键经历必须有材料出处。
- “高级、松弛、治愈、有审美”等词必须转成可观察证据。
- 不能因为照片或装修风格推断财富、性格、家庭关系或人生经历。
- 账号档案未通过时，允许做研究，不允许写第一人称成稿。
