# 跨赛道迁移协议

## 先抽象，后落地

把源内容拆成四层：

1. 事实层：人物、事件、数字、场景。
2. 叙事层：计算、反转、对比、实验、告白等表达结构。
3. 心理层：时间稀缺、被忽视、身份焦虑、控制感等情绪。
4. 行动层：观众看完想转发、评论、收藏或改变什么。

迁移优先保留心理层和行动层，选择性重建叙事层，默认舍弃源作者独有事实层。

## 机制等式

源受众张力 + 源承重杠杆 + 目标账号真实证明场景 = 新选题

示例：

- 源张力：人生看似很长，真正自由支配时间很少。
- 承重杠杆：用计算制造认知冲击，再激活时间被偷走的情绪。
- 目标证明场景：茶室提供一段主动停下来的真实空间。
- 新选题：我们以为还有几十年，真正属于自己的时间少得可怜。

目标账号不是时间管理专家。它只对“如何给自己留下一段不被催促的时间”有真实发言权。

## 失败模式

- 只把“上班”替换成“喝茶”，句式和论证都不变。
- 为了匹配源故事，虚构目标人物的创伤或人生转折。
- 内容前 90% 与账号无关，最后突然出现产品。
- 把情绪机制夸张成无法支持的精确事实。
- 因为源内容爆过，就跳过目标受众适配。

## 迁移检查

- 新内容能否独立成立？
- 目标账号的真实场景是否参与了论证，而非只在结尾露出？
- 熟悉原内容的人会认为这是同一机制的新表达，还是改词搬运？
- 不熟悉原内容的人能否理解完整逻辑？
- 产品出现后是否降低可信度？
