# SDT 逐字稿流畅度

独立检查逻辑衔接、信息密度和口播流畅度。完整 SDT 生产模式已经包含改稿授权，可在诊断后直接产出修复版；单独调用时先诊断，再询问是否标记式改稿。

## 工作流

1. 先确认拍摄方式：纯口播、白板、空间走拍、采访或剧情。
2. 按自然话题切换分段，标注段落功能。
3. 检查逻辑断裂、密度下降和口播卡壳。
4. 标注高、中、低风险并引用具体原文。
5. 修复时不改变选题核心、事实和产品落点。
6. 完整生产模式输出两个版本：标记式修改稿与干净可拍稿。

## 风险等级

- 高风险：逻辑跳跃、承诺不兑现、关键概念没有解释。
- 中风险：信息重复、铺垫过长、句子连续过密。
- 低风险：口头词、停顿和节奏可微调，但不影响理解。

## 规则

- 白板或场景动作相关提示词不能被当作赘词误删。
- 删除论证前先判断观众能否自行补全缺失信息。
- 保持账号本人语气，不把自然停顿磨成均匀 AI 句式。
- 事实不确定处用核验标记，不做顺口但虚假的补写。
