# SDT 内容资产系统

SDT 的轻量归档可用于每次生产；当素材达到数量和来源门槛时，按本技能的工程规则独立升级为重型内容工程。

## 轻量归档

每次生产保存：

- account：账号档案版本
- sources：来源证据与采集时间
- mechanisms：传播机制卡
- topics：候选和评分
- productions：标题、封面、开头、正文与版本
- performance：发布链接和可见指标
- reviews：假设是否成立、可复用规律和失败原因

使用 references/archive-schema.md 的命名和状态字段。原始来源不改写，创作版本使用新文件。

## 升级门槛

素材达到以下任一规模时，先做重型工程审计：

- 可处理文本不少于 50 个
- 或正文不少于 80000 字

并至少覆盖两类来源。不要为少量内容强建重型系统。

审计通过后才建立原始素材副本、内容单元库、主题地图、装配稿、处理状态和去重关系。原目录不改写；先用 3–5 篇样本验证结构，再批量推进。

## 回填纪律

- 发布前假设与发布后结论分开。
- 点赞、收藏、评论、播放和粉丝量写采集时间。
- 一次爆发不升级为长期规律；至少记录多个同机制样本。
- 失败稿不删除，标出失败环节，供后续对照。
