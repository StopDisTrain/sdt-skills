# SDT 视频开头

先做正文质量、素材丰富度和当前开头诊断；通过后再生成开头并嵌入 SDT 成稿。

## 前置门

必须有完整正文或完整结构。只有选题和标题时停止生成，先回到 sdt-content。

## 工作流

1. 检查正文是否有真实数据、转变、金句、权威或具体痛点。
2. 提取话题、观看理由和账号可信度。
3. 按素材提取、可信素材补充、悬念制造三类方法各生成候选。
4. 删除正文无法兑现、需要伪造数据或不适合口播的候选。
5. 选 Top 3，并把第一名嵌回逐字稿测试前后衔接。

## 硬规则

- 不假设观众看过标题。
- 不在第一句直接给完答案。
- 不使用虚构成绩、客户量、经验年限或权威背书。
- 素材增补只能使用已核实材料；否则写成待采集需求，不能写进成稿。
- 开头必须能由目标账号本人自然说出口。

## 开头公式

开头至少包含两项：

- 话题：观众立刻知道在讲什么。
- 观看理由：数据、反差、损失、未完成问题或具体利益。
- 可信度：真实经历、可核验结果、具体现场或清晰观察。

优先结构：具体反差 + 未完成问题；真实结果 + 反转；痛点场景 + 新解释。避免连续自问自答和空泛命令句。
